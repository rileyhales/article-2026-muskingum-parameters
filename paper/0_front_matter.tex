  \begin{highlights}
    \item{We investigate two existing Muskingum routing code implementations finding deficiencies enforcing valid parameter combinations contribute to peak flow and peak timing errors.}
    \item{Six global or continental streams datasets contain wide-ranging lengths which make single time step simulations impossible.}
    \item{The new Muskingum routing code implementation, river-route, forces properly parameterized routing and demonstrates incrementally improved computational efficiency.}
  \end{highlights}
